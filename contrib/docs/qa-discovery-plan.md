# Backstage QA Platform — API Test Generation

> **For agentic workers:** Use `superpowers:executing-plans` or `superpowers:subagent-driven-development` to work through this plan task-by-task. Steps use `- [ ]` checkbox syntax for tracking.

**Goal:** Set up Backstage as an AQ platform where Ollama Cloud generates Playwright API tests from OpenAPI specs registered in the catalog — one UI form click triggers test generation.

**Architecture:** Backstage hosts the API catalog and a Scaffolder template (form UI). A custom TypeScript Scaffolder action reads the submitted spec, calls Ollama Cloud's `/v1/chat/completions` endpoint with a structured prompt, and writes a runnable Playwright test file to the workspace. Tests execute outside Backstage with `npx playwright test`.

**Tech Stack:** Backstage latest stable, TypeScript, Node.js 22+, Yarn, Ollama Cloud (OpenAI-compatible endpoint), Playwright

---

## Scope

API testing only. Web and mobile testing are deferred.

**Intentionally out of scope for MVP:** SSO, Postgres, Docker, Kubernetes, permissions framework, production deployment, CI/CD.

- [ ] **Step 5.2: Write the action**

Create `plugins/scaffolder-backend-module-ollama/src/actions/generate-tests.ts` with this content:

```typescript
import { createTemplateAction } from '@backstage/plugin-scaffolder-node';
import fs from 'fs';
import path from 'path';

export const createOllamaTestGenAction = () => {
  return createTemplateAction<{
    model: string;
    openApiSpec: string;
    apiBaseUrl: string;
    outputFileName: string;
  }>({
    id: 'ollama:generate-api-tests',
    description: 'Generate Playwright API tests from an OpenAPI spec via Ollama Cloud',
    schema: {
      input: {
        type: 'object',
        required: ['openApiSpec', 'apiBaseUrl'],
        properties: {
          model: {
            type: 'string',
            title: 'Ollama model',
            default: 'deepseek-coder',
          },
          openApiSpec: {
            type: 'string',
            title: 'OpenAPI spec (JSON or YAML)',
          },
          apiBaseUrl: {
            type: 'string',
            title: 'API base URL',
            description: 'The live base URL of the API under test',
          },
          outputFileName: {
            type: 'string',
            title: 'Output file name',
            default: 'generated-tests.spec.ts',
          },
        },
      },
      output: {
        type: 'object',
        properties: {
          testFile: { type: 'string', title: 'Path to generated test file' },
        },
      },
    },

    async handler(ctx) {
      const {
        model = 'deepseek-coder',
        openApiSpec,
        apiBaseUrl,
        outputFileName = 'generated-tests.spec.ts',
      } = ctx.input;

      const ollamaUrl = process.env.OLLAMA_CLOUD_URL;
      const ollamaKey = process.env.OLLAMA_CLOUD_API_KEY ?? '';

      if (!ollamaUrl) {
        throw new Error(
          'OLLAMA_CLOUD_URL is not set. Export it in your shell before starting Backstage.',
        );
      }

      const prompt = [
        'You are a senior QA engineer. Generate a complete Playwright API test suite in TypeScript.',
        '',
        'Requirements:',
        '- Use @playwright/test and request.newContext()',
        `- Base URL for all requests: ${apiBaseUrl}`,
        '- Cover: happy path for every endpoint, at least one 400 error case, at least one 404 error case',
        '- Assert both status codes and key response body fields',
        '- Use descriptive test names (describe + it blocks)',
        '- Output ONLY the TypeScript code — no markdown fences, no prose explanations',
        '- The file must run as-is with: npx playwright test',
        '',
        'OpenAPI spec:',
        openApiSpec,
      ].join('\n');

      ctx.logger.info(
        `Calling Ollama Cloud: ${ollamaUrl}/v1/chat/completions (model: ${model})`,
      );

      const res = await fetch(`${ollamaUrl}/v1/chat/completions`, {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json',
          ...(ollamaKey ? { Authorization: `Bearer ${ollamaKey}` } : {}),
        },
        body: JSON.stringify({
          model,
          messages: [{ role: 'user', content: prompt }],
          temperature: 0.1,
          stream: false,
        }),
      });

      if (!res.ok) {
        throw new Error(`Ollama Cloud returned ${res.status}: ${await res.text()}`);
      }

      const data = (await res.json()) as {
        choices: Array<{ message: { content: string } }>;
      };

      const raw = data.choices[0]?.message?.content;
      if (!raw) {
        throw new Error(
          'Ollama Cloud returned an empty response. Try a different model or reduce spec size.',
        );
      }

      // Strip markdown fences if the model added them despite instructions
      const testCode = raw
        .replace(/^```(?:typescript|ts)?\n?/m, '')
        .replace(/\n?```$/m, '')
        .trim();

      const outputFile = path.join(ctx.workspacePath, outputFileName);
      fs.writeFileSync(outputFile, testCode + '\n');

      ctx.logger.info(`Test file written to: ${outputFile}`);
      ctx.output('testFile', outputFile);
    },
  });
};
```

apiVersion: scaffolder.backstage.io/v1beta3
kind: Template
metadata:
  name: generate-api-tests
  title: Generate API Tests (Ollama Cloud)
  description: >
    Paste an OpenAPI spec and get a runnable Playwright test suite
    generated by Ollama Cloud.
  tags:
    - qa
    - ai
    - playwright
spec:
  owner: guests
  type: qa-tool

  parameters:
    - title: API Details
      required:
        - apiBaseUrl
        - openApiSpec
      properties:
        apiBaseUrl:
          title: API Base URL
          type: string
          description: 'Live URL of the API under test'
          ui:placeholder: 'https://petstore3.swagger.io/api/v3'
        outputFileName:
          title: Output file name
          type: string
          default: generated-tests.spec.ts

    - title: AI Configuration
      properties:
        model:
          title: Ollama Model
          type: string
          enum:
            - deepseek-coder
            - codellama
            - llama3
            - mistral
          default: deepseek-coder
          description: 'deepseek-coder gives best results for API test code'

    - title: OpenAPI Spec
      required:
        - openApiSpec
      properties:
        openApiSpec:
          title: OpenAPI Spec (JSON or YAML)
          type: string
          ui:widget: textarea
          ui:options:
            rows: 20

  steps:
    - id: generate
      name: Generate tests via Ollama Cloud
      action: ollama:generate-api-tests
      input:
        model: ${{ parameters.model }}
        openApiSpec: ${{ parameters.openApiSpec }}
        apiBaseUrl: ${{ parameters.apiBaseUrl }}
        outputFileName: ${{ parameters.outputFileName }}

  output:
    text:
      - title: Done
        content: |
          Tests generated.

          **File:** `${{ steps.generate.output.testFile }}`

          **Run them:**
          ```
          cd ~/work/qa-tests/<api-name>
          npm init -y && npm i -D @playwright/test
          cp <file-path-above> .
          npx playwright test
          ```
```

## Gotchas

- **Spec quality determines output quality.** Missing descriptions, examples, or schemas produce weak tests. The Petstore spec is good. Your own API spec may not be — fix the spec first.
- **AI hallucinates endpoints.** Always run the tests. A failing test on `/pet/findBySatus` (typo) is a prompt artifact, not a real bug.
- **Model context limits.** Large specs (>4K tokens) may get cut off. Options: smaller spec, model with larger context window, or test one endpoint group at a time.
- **Env vars don't survive shell restarts.** Add `OLLAMA_CLOUD_URL` and `OLLAMA_CLOUD_API_KEY` to `~/.zshrc` or use `direnv`.
- **Module not loading.** If the `ollama:generate-api-tests` action isn't found, the module wasn't registered. Double-check `packages/backend/src/index.ts`.
- **Prompt drift.** The prompt in `generate-tests.ts` is v1. As you tune it, version it in `prompts/api-tests.md`. Don't lose what worked.
- **Backstage upgrades break custom actions.** After any `yarn upgrade` on Backstage, re-run `yarn tsc --noEmit` in the module and retest the end-to-end flow.
